# 전체 테마색과 방문자 자료 등록

설정 및 관리 → 관리 홈 → **전체 테마색**에서 프리셋 또는 직접 선택한 색을 저장합니다. 기본값은 대표 이미지의 따뜻한 주황색(`#b85c12`)입니다. 운영 관리자가 저장한 색은 서버에 보관되며 전사·자료 검색·관리 화면과 파형에 적용됩니다. 열린 다른 화면은 최대 15초 후 또는 창으로 돌아올 때 갱신됩니다. 밝은 색상은 흰 버튼 글자의 대비가 유지되도록 어둡게 조정합니다. 회의 도우미의 정정·주의·참고·일치 색상은 의미를 유지합니다.

방문자도 자료 검색 → 워크스페이스 만들기 → **파일 선택 / 폴더 선택**으로 MD·TXT·CSV·TSV·XLSX를 업로드할 수 있습니다. 업로드 완료 후 자동으로 검색 자료를 준비합니다. 본인 자료의 검색·근거 조회·자료 준비 재시도·설정·삭제를 지원합니다. AI 답변은 기존 서버 연결과 문서 활용 동의가 필요합니다.

방문자가 등록한 워크스페이스는 해당 방문자와 관리자만 볼 수 있습니다. 공용 워크스페이스는 기존처럼 검색할 수 있지만 방문자가 수정하거나 삭제할 수 없습니다. 공유 서버 폴더 연결과 전역 모델 설정 권한은 확대하지 않습니다. 비로그인 방문자는 브라우저 세션이 만료되거나 삭제되면 기존 개인 자료 접근을 잃을 수 있습니다. 업로드 자료는 명시적으로 삭제하기 전까지 보존됩니다.

기존 자료는 공유 상태를 유지합니다. RAG 스키마 7은 업로드 세션에 소유자를 추가하며, 신규 방문자 자료만 개인 자료로 등록합니다. 업로드 크기·파일 수·전체 저장량 제한과 CSRF 검사도 유지합니다.

## 검증과 반영

2026-09-20: 전사 서버 208개, 프런트엔드 56개 테스트와 프로덕션 빌드 통과. RAG 전체 실행은 293개 통과 후 프런트엔드 빌드가 정적 파일 디렉터리를 교체하는 순간 1개 테스트의 초기화가 실패했으며, 해당 테스트를 단독 재실행해 통과했습니다. 기존 엑셀 표시 형식 검사는 현재 소스 기준 재검증을 통과했습니다.

공개 HTTPS 데모에서 관리자 색상 저장, 별도 방문자 브라우저 적용, 열린 화면 자동 갱신, 방문자 파일 업로드·실제 임베딩 색인·근거 검색, 다른 방문자의 접근 차단, 390px 모바일 레이아웃을 확인했습니다. 시험 자료는 정리했고 최종 색상은 서재 오렌지입니다. 상시 STT/RAG 서비스와 공개 데모에 반영했습니다.
