# 로컬 음성 파형 플레이어 — 2026-09-09

## 사용 방법

- 대본 왼쪽의 ▶ 또는 시간을 누르면 해당 발화 시작으로 이동해 재생한다. 발화의 시작부터 끝까지 녹색 배경과 녹색 파형으로 강조하며, 화자 이름과 선택 구간을 플레이어 아래에 표시한다.
- 기본 화면은 12초 구간이다. `+` / `−`로 4·8·12·24·48·96초 범위로 조절한다. 긴 발화를 선택하면 가능한 범위에서 구간을 넓힌다. 전체 녹음 길이로 축소하는 파형은 제공하지 않는다.
- 아래 탐색 바의 녹색 세로선과 `재생` 시간은 실제 재생 위치를 나타낸다. 수동 탐색 중에는 흰색 원형 손잡이가 화면 중심 위치를 나타내므로 재생 위치와 구분할 수 있다. 시간 표시는 양 끝에서도 바 안에 유지된다.
- 파형 내부의 스크롤 막대는 숨긴다. 파형을 좌우로 드래그하거나 스크롤해서 탐색한다. 아래 탐색 막대와 좌우 버튼으로 멀리 이동할 수도 있다. 탐색만으로 재생 시간은 바뀌지 않는다. 파형을 클릭하면 재생 위치가 바뀐다.
- 재생 중에는 재생 위치를 따라간다. 직접 탐색하면 자동 이동이 멈추며, `재생 위치로`를 누르면 다시 따라간다. 파형 영역에 키보드 초점을 두면 좌우 방향키로 탐색하고 Home/End로 시작/끝에 이동한다.
- 재생/일시 정지, 10초 이동, 0.75–2배속을 지원한다. 시간은 시:분:초.백분의초로 표시한다.
- 새로고침 후에는 같은 원본 파일을 다시 연결한다. 파일 연결과 파형 생성은 업로드를 발생시키지 않는다.

## 구현

`LocalAudioPlayer.tsx`가 로컬 File의 Blob URL로 HTMLAudioElement를 재생한다. `WaveformViewport.tsx`는 실제 길이를 가진 가상 스크롤 영역과 화면 너비만큼의 canvas를 사용한다. 300분 파일에서도 전체 길이의 대형 canvas나 수십만 DOM 요소를 만들지 않는다.

`waveform.worker.ts`는 Mediabunny 1.56.0의 BlobSource 및 AudioSampleSink로 필요한 구간만 읽는다. 10초 단위, 초당 100개 peak로 축약하며 최대 32개 타일을 LRU 방식으로 보관한다. 원본 읽기 캐시는 4 MiB이며 전체 파일을 PCM으로 디코딩하지 않는다. 디코딩한 패킷은 처리 직후 닫는다. 파일 변경/연결 해제 때 Worker를 종료하고 Blob URL을 해제한다. 탐색 요청이 바뀌면 이전 범위 계산을 중단하고 최신 범위를 우선한다.

스테레오 채널을 더해 상쇄시키지 않고 각 채널 절댓값의 최댓값을 사용한다. 디코더의 음수 타임스탬프와 타일 경계를 잘라내며 무음에는 인공 파형을 생성하지 않는다. 화면에서는 진폭을 제곱근 스케일로 표시해 작은 소리도 식별할 수 있게 한다.

참고: [Mediabunny의 로컬 파일 읽기](https://mediabunny.dev/guide/reading-media-files), [오디오 구간 디코딩](https://mediabunny.dev/guide/media-sinks).

## 호환성

HTTPS 또는 localhost에서 사용한다. 이번 검증에서는 Chrome의 WAV(PCM), MP3, FLAC, M4A(AAC) 파형이 동작했다. 브라우저의 디코더에 따라 지원 여부가 다르다. ALAC 방식의 M4A는 이번 Chrome 환경에서 로컬 재생 자체를 지원하지 않았다. 파형 디코딩이 불가능하면 오류를 안내하며 가짜 파형을 그리지 않는다. 파형 디코더만 지원하지 않고 브라우저 재생이 가능하면 재생 기능은 유지한다. 서버 STT가 받는 파일 형식과 브라우저의 로컬 재생 지원 범위는 다를 수 있다.

## 검증

- 프런트엔드 12개 단위 테스트: 스테레오, 패킷/타일 경계, 무음, 300분 범위 및 시계 포함.
- 실제 Chrome의 별도 프로필과 모의 API 대본을 이용해 대본 재생/시간 이동, 녹색 픽셀, 이름 표시, 드래그/스크롤/키보드, 자동 이동 복귀, 확대/축소, 배속, 파형 클릭을 검증했다. UI 검증용 대본만 사용했으며 실제 사용자 대본은 수정하지 않았다.
- 11분 AAC M4A를 로컬로 연결하고 2분 54초 구간으로 직접 이동했다. 추가 업로드가 없고 실제 peak가 생성되는 것을 확인했다.
- 300분(18,000초) 합성 AAC M4A를 연결하고 4시간 59분(17,940초) 지점의 파형과 재생 시간 이동을 확인했다. 각 화면 요청은 이 검증에서 1–3개의 타일만 반환했다.
- 1440px, 1024px, 390px 화면을 확인했다. 작은 높이의 데스크톱에서는 오른쪽 패널 내부를 스크롤할 수 있고, 모바일에서는 플레이어가 대본 위에 배치된다.
- 빠르게 일시 정지했을 때 발생하는 정상적인 play() AbortError를 오류로 표시하지 않도록 했다. 화면 전환 중 일시적인 0 너비도 무시한다.
- 결과 요약: [waveform-validation.json](waveform-validation.json).

배포는 새 정적 assets를 먼저 복사한 후 index.html을 원자적으로 교체한다. 서버 재시작이나 대본 변경은 하지 않는다. [배포 결과](waveform-deployment.json)에서 Tailscale 정적 파일 일치, 서버 프로세스 유지, 기존 483개 발언 보존을 확인했다.
