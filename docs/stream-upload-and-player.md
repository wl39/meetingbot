# 업로드 중 전사 / 로컬 재생 / 화자 이름 — 2026-09-09

## 사용자 동작

- 파일을 선택하면 오른쪽 플레이어에서 브라우저의 로컬 File/Blob URL로 재생한다. 재생을 위해 서버 원음 저장이나 다운로드를 하지 않는다.
- 대본 시간을 누르면 원본의 해당 위치를 재생한다. 현재 구간 강조, 10초 이동, 재생 속도 조절을 제공한다. 확대 파형·발화 구간 강조·좌우 탐색은 [로컬 파형 플레이어](local-waveform.md)를 참고한다. 새로고침 후에는 원본 파일을 다시 연결해야 한다. 파일 정보가 저장된 새 세션에서는 이름·크기가 같은 원본을 확인한다.
- 화자를 A/B/C 배지로 표시한다. 화자 이름의 `전체 적용`은 세션의 해당 speaker_id 이름을 갱신한다. 같은 화자의 모든 발언과 TXT/SRT 내보내기에 반영되며 후속 분석이 이름을 초기화하지 않는다. 분석 전의 미확정 화자는 임의로 A/B를 붙이지 않는다.

## 스트리밍 계약

1. `POST /api/stt/files/stream` — filename, size, options를 등록하고 session_id, job_id, chunk_bytes를 받는다.
2. `PUT /api/stt/files/{sid}/chunks/{index}` — 정해진 크기의 바이너리 블록을 전송한다. 마지막 블록만 짧을 수 있다. 잘못된 길이·인덱스·중복 블록은 거부한다.
3. `POST /api/stt/files/{sid}/finish` — 모든 블록이 수신됐는지 확인하고 업로드를 확정한다. 전체 분석 완료를 기다리지 않는다.
4. 기존 세션 조회에서 업로드 비율, 전사 비율과 중간 대본을 확인한다. 삭제/취소는 기존 세션 DELETE를 사용한다.

M4A 클라이언트는 작은 로컬 헤더 읽기로 최상위 moov 위치를 찾아 그 블록들을 먼저 보낸다. 서버는 희소 임시 파일에 블록을 저장하고, FFmpeg에 127.0.0.1의 임시 HTTP Range 리더를 제공한다. 이 리더는 임의 경로 비밀값을 요구하고 Tailscale 경로에는 공개하지 않는다. 아직 받지 않은 블록의 읽기는 수신까지 기다린다. FFmpeg direct AVIO를 사용해 M4A의 mdat를 끝까지 미리 읽는 동작을 피한다. 허용 컨테이너는 WAV/MP3/MOV(M4A)/FLAC이며 MOV 외부 참조는 기본 비활성화 상태다.

PCM은 디스크에 계속 기록된다. 최초 12초 구간과 후속 30초 구간에 양쪽 최대 2초 문맥을 사용하여 준비된 구간부터 전사한다. 따라서 업로드가 끝나기 전에 대본을 볼 수 있다. 화자 분석은 전체 오디오 수신과 전사 후 수행한다. 아주 짧거나 빨리 전송되는 파일은 업로드가 먼저 끝날 수 있으며 재생 중인 오디오처럼 도착한 바이트마다 자막을 만드는 방식은 아니다.

120초 동안 새 블록이 도착하지 않으면 중단으로 처리한다. 완료·실패·취소 후 변환 프로세스, 임시 Range 리더, 파일을 정리한다. 업로드 재개는 아직 지원하지 않는다. 기존 multipart 파일 API와 원음 재처리 경로도 유지한다.

## 검증

- 백엔드 55개 테스트 통과: WAV 및 moov가 끝에 있는 M4A에서 업로드 100% 전에 대본 생성, 전체 완료, 순서/크기/중복/인증/취소, 기존 300분 경계 및 파일 정리 포함.
- 프런트엔드 6개 테스트 및 빌드 통과. 여러 블록에 걸친 M4A moov 우선 전송 및 작은 파일의 중복 방지를 확인했다.
- 별도의 모의 서버에서 브라우저를 사용해 파일 선택, 업로드, A/B 배지, A→임완규 전체 반영, 대본 2초 클릭→Blob 원본 2초 재생을 확인했다.
- 실제 배포 서버의 Tailscale HTTPS에서 Turbo와 Community-1을 사용하는 짧은 M4A 스트리밍 API 검증 결과는 [실행 기록](stream-upload-smoke.json)에 저장한다. 업로드 완료 전 대본 생성 자체는 지연 전송을 사용하는 모의 모델 회귀 테스트로 검증했다.
- 사용자 승인에 따라 기존 약 71분 녹음의 화자 분석을 중단하고 서버를 재시작했다. 대본 483개 발언을 별도로 백업했으며, 재시작 후 발언 JSON의 SHA-256이 일치함을 확인했다. 기존 세션은 INTERRUPTED로 남으며 화자 분석을 완료하려면 원본을 다시 입력해야 한다.
