# 현재 제약과 미검증 범위

## 구현된 범위

외부 기기의 폴더 업로드·자동 색인, 서버 허용 폴더 탐색, 영속 미리보기, 여러 워크스페이스, MD/TXT/CSV/TSV/XLSX 추출, 고정된 로컬 E5 모델, 원문 위치/스냅샷, Qdrant + FTS5 RRF 검색, 증분 갱신, 기존 READY 유지, 취소/재시작 복구, 전송 승인·철회, CLIProxyAPI 어댑터, 프로덕션 React 웹, macOS LaunchAgent, Tailscale IP/HTTPS 설정, 백업/빈 경로 복구 CLI가 구현되어 있다.

## 부분 구현과 의도적 제한

- 업로드는 MD/TXT/CSV/TSV/XLSX와 선택 폴더의 파일 구조를 지원한다. ZIP, PDF, DOCX, 빈 폴더, 원격 기기 변경 자동 동기화, 개인 계정/ACL은 제공하지 않는다. 브라우저를 새로고침하면 폴더를 다시 선택해야 한다. 파일별 같은 화면 재시도와 서버의 수신 상태 복구를 제공한다.

- 표는 헤더+한 행부터 청킹한다. 숫자/날짜/비율/앞자리 0/수식 원문을 보존하지만 복잡한 다중 헤더와 다중 표의 자동 해석은 하지 않고 파일 확인 필요 상태로 둔다. 병합 범위를 기록하되 원본 빈 셀을 임의로 채우지 않는다. 복잡한 Excel 사용자 지정 표시 형식을 모두 재현하지는 않는다.
- 텍스트는 제목 섹션과 원본 줄을 보존한다. 문단·줄·문장 경계를 우선하되 길이가 큰 코드 블록은 모델 한도에 맞게 분할할 수 있다. full Markdown AST 편집기는 아니다.
- 키워드 검색은 unicode61와 한국어 두 글자 토큰의 보완 방식이다. 형태소 검색이나 일반적인 한국어 품질을 보장하지 않는다. 5개 합성 평가만 실제 모델로 확인했다.
- 답변은 비스트리밍 JSON 응답 형식으로 검증한다. CLIProxyAPI 로컬 서버와 기본 모델 설정, Codex OAuth UI, 모델·프롬프트 관리를 구현했다. 2026-09-09 실제 Codex 계정의 gpt-5.6-terra 호출·JSON 형식, 합성 프롬프트 4개 상황과 샘플 공간 2개의 실제 RAG 답변을 확인했다. 일반 업무 자료 전반의 품질은 별도 평가가 필요하다. 공급자 스트리밍은 구현하지 않았다.
- 인용 ID 검증은 답변 문장 전체의 사실 검증이 아니다. 전체 표의 합계·평균 질의는 미지원으로 반환한다. 고정된 보수적 표현 탐지여서 모든 집계 질문 표현을 이해하는 것은 아니다.
- 파서 작업은 시간 제한 subprocess다. 임베딩 실행 중 즉시 강제 취소하는 기능은 없으며 짧은 배치 사이에 취소를 확인한다. 서버 강제 종료 후 같은 작업을 자동 이어서 진행하지 않고 FAILED로 표시해 명시 재시도한다.
- 단일 관리자·단일 서버 프로세스·단일 ingestion worker다. 대규모 corpus, 다수 동시 사용자, OS별 최적화는 검증하지 않았다. 확장이 필요하면 Qdrant 서버 모드와 별도 저장소 서비스로 전환한다.
- 웹에서 청크 크기·겹침·검색 근거 수를 저장하고 기존 자료를 재준비할 수 있다. 청크 수는 문서 내용과 토큰화 결과로 결정된다. 임베딩은 현재 E5 모델의 고정 revision만 설치하며 임의 임베딩 모델 교체는 제공하지 않는다. 다운로드 중 즉시 취소·속도·바이트 단위 진행률은 제공하지 않는다.
- Windows에서는 별도 Win32 파일 핸들로 폴더를 읽고 junction·symlink 등 reparse point를 차단한다. macOS/Linux의 Unix 디렉터리 핸들 보호를 유지하며 Windows 분기와 파일 잠금은 추가했다. 실제 Windows 장치의 설치·파일 읽기는 아직 검증하지 않았다.
- 버전 보존/삭제는 API를 제공하며 웹 버전 목록은 조회 중심이다. 자동 보관 기한 기반 버전 정리는 기본 꺼짐이고 질문 기록만 30일, 미리보기 기록은 7일 이후 삭제한다.
- 원본 파일이 삭제돼도 과거 snapshot이 남는다. 앱 내 삭제는 SSD의 물리적 완전 삭제를 보장하지 않는다. 백업도 별도 정리해야 한다.
- 디렉터리 항목 cursor는 현재 디렉터리 열거 순서의 offset이다. 목록 조회 사이에 파일이 변경되면 재조회해야 하며 미리보기/색인 단계가 최종 수집 판단을 한다.

## 미검증

별도 외부 네트워크/외부 기기의 접속, 실제 계정의 요금/사용량 제한과 일반 자료 생성 품질, 새로운 Mac에서의 처음부터 설치, 다른 OS, 대용량 성능, 전원 장애 시 디스크 손상, 일반 한국어 검색 정확도는 검증하지 않았다. Tailscale HTTPS 서버 경유와 기존 화면의 headless Chrome 동작, STT 테스트는 별도로 검증했다. 이번 폴더 업로드 화면은 Mac 잠금으로 시각 검증을 수행하지 못했다.
