# 선택과 가정

1. 제공된 문서는 이번 RAG 구현의 요구사항 자료로 참고했다. 사용자의 실제 요청은 기존 미팅봇 RAG 작업과 Tailscale IP 접속이다. 인터넷 익명 공개나 LLM 외부 전송은 활성화하지 않았다.
2. 기존 STT가 서비스 중이므로 별도 `rag/pyproject.toml`, `rag/uv.lock`, `.env.rag`, LaunchAgent를 사용했다. STT Python 의존성과 작업 상태를 재사용하지 않는다. 관리자 키 검증만 재사용한다.
3. 폴더 추가 답변이 없어 `~/MeetingDocs`를 허용 루트로 준비했다. 개인정보 없는 `sample-project-a`/`sample-project-b`만 생성했다. 사용자의 Documents 전체를 허용하거나 기존 개인 문서를 수집하지 않았다.
4. 기존 Tailscale :443/:8765는 STT가 사용하므로 RAG는 HTTPS :8443 및 IP 진입 :8766을 사용한다. IP 진입은 인증서와 일치하는 MagicDNS HTTPS 이름으로 이동한다.
5. 초기 지원 검증 장치는 이 Mac의 Darwin arm64다. 모델은 MPS 실행을 확인했고 RuntimeError 시 CPU fallback을 제공한다. 다른 OS/macOS 장치의 설치 성공을 검증한 것은 아니다.
6. E5 `intfloat/multilingual-e5-small` revision `614241f622f53c4eeff9890bdc4f31cfecc418b3`을 HF API에서 확인하고 고정했다. 384차원, 정규화, query/passage 접두어(코드의 정확한 값은 `query: ` / `passage: `), 모델 입력 512토큰이다. 모델 준비 후 서버는 local_files_only로 로드한다.
7. FTS5 unicode61 + 한국어 연속 두 글자 토큰을 사용한다. 형태소 분석을 구현했다고 주장하지 않는다. RRF는 순위를 합치며 유사도를 정답 확률로 표시하지 않는다.
8. CSV/TSV는 원본 문자열을 보존한다. XLSX는 원본 값/숫자 형식/수식/캐시를 분리한다. 불명확한 헤더·다중 표는 확인 필요로 실패 처리한다. 표 청크는 보수적으로 헤더+한 행부터 구성하며 큰 행은 추가 분할한다. 전체 범위 집계는 지원하지 않는다.
9. 과거 버전은 기본 무기한 보존한다. 자동 삭제 대신 명시 삭제와 보존 설정 API를 제공한다. 활성·보존·구축 중 버전은 삭제를 거절한다.
10. 소유자의 선택에 따라 프로젝트 코드를 [MIT License](../../LICENSE)로 공개한다. 외부 패키지와 모델에는 각자의 라이선스·접근 조건이 적용된다.

## 운영 제한의 초기값

| 항목 | 초기값 |
|---|---:|
| 디렉터리 목록 페이지 | 100개, 최대 20,000개 확인 / 3초 |
| 재귀 스캔 | 파일·폴더 합계 2,000개, 깊이 12, 45초 |
| 파일 / 전체 읽기 | 10 MiB / 100 MiB |
| XLSX 압축 해제 크기 | 50 MiB |
| XLSX 시트 / 행 / 열 / 셀 | 20 / 20,000 / 100 / 200,000 |
| 문서 파싱 / 청킹 | 단계별 15초 |
| 본문 청크 / 겹침 | 약 320 / 48 모델 토큰 |
| 최대 버전 청크 | 25,000 |
| 벡터 / 키워드 후보 / 최종 근거 | 20 / 20 / 6 |
| 최소 벡터 후보 유사도 | 0.76 (정확도 임계 확률 아님) |
| LLM 입력 / 출력 / timeout | 16,000자 / 1,200토큰 / 45초 |
| 질문 / 미리보기 기록 보관 | 30일 / 7일 |

이 값은 운영 자원 제한이며 처리 속도·메모리·한국어 정확도 보장이 아니다. 파일과 표 형식, 모델 CPU/MPS에 따라 달라진다.
