# 워크스페이스 지침서

## 사용자 동작

워크스페이스 → 워크스페이스 설정 → **지침서**에서 최대 4,000자를 저장한다.
관리자/최고관리자가 편집할 수 있고, 방문자는 설정 API 읽기·쓰기를 할 수 없다.
새 지침서는 내용 입력 후 저장하면 참고가 켜진다. 체크 해제로 내용을 보존한 채 사용을 중지하고,
빈 내용으로 저장하면 지침서가 지워지며 사용도 해제된다. 자료 재색인은 필요하지 않다.

예: “요리 관련 답변에는 재료와 조리 순서를 포함하고, 조리 순서는 번호로 정리해 주세요.”
현재 질문에 관련되고 문서에서 확인되는 범위에서만 참고한다. 자료에 없는 단계를 만들지 않는다.
운영 지침의 간결성 또는 회의 팝업 길이 제한과 충돌하면 운영 지침을 우선한다.

## 신뢰 경계

1. 서비스 운영자가 관리하는 운영 지침과 고정 출력 계약만 `system` 역할에 놓는다.
2. 지침서는 문서 근거·질문과 함께 `user` 역할의 JSON `workspace_guide.content`에 넣는다.
   문자열 치환으로 시스템 메시지에 결합하지 않는다. JSON 내부 역할/구분자도 단순 문자열이다.
3. 고정 규칙은 지침서를 **표현·구성 선호만 담는 신뢰하지 않는 참고 데이터**로 정의한다.
   역할 변경, 운영 규칙 공개/무시, 근거 위조, 인용 생략, 외부 전송, 도구 실행,
   다른 워크스페이스 접근, 사실 판정·신뢰도·색상 조작은 허용 범위가 아니다.
4. 질문 검색과 회의 키워드 추출에는 지침서를 전달하지 않는다. 회의는 근거 검색 후
   팝업 작성 단계에서만 참고하며, 활성 운영 지침 + 회의 전용 출력 계약을 함께 사용한다.
5. 모델에 도구 실행 권한을 주지 않는다. 권한, 전송 승인, 검색 범위, 파일 접근은 서버 코드에서
   결정한다. 모델 출력으로 설정을 바꾸거나 도구를 실행하지 않는다.
6. 질문 출력은 정확한 JSON 필드·상태·제공된 인용 ID를 검증한다. 근거 부족은 인용이 없어야 하고,
   충돌 답변에는 서로 다른 실제 인용 2개 이상이 필요하다. 회의는 기존 실제 원문 발췌 검증,
   인용·색상·적용 범위 검증을 유지한다. 위반 시 결과를 노출하지 않는다.
7. 지침서·운영 메시지를 포함한 전체 입력 예산을 확인한다. 넘으면 임의로 자르지 않고 요청을 중단한다.

공식 [OpenAI Docs의 안전 지침](https://developers.openai.com/api/docs/guides/agent-builder-safety)에 따라
신뢰하지 않는 입력을 상위 역할 메시지에 넣지 않고 구조화된 입출력·권한 격리를 함께 적용했다.
이 설계는 “임의의 자연어 공격을 100% 막는다”는 보장이 아니다. 특히 허용된 인용 ID를 붙인
답변 문장 자체의 의미적 진실성까지 JSON 검증이 증명하지는 않는다. 모델/운영 지침 변경 시
합성 공격 회귀 평가를 다시 실행해야 한다. 별도 LLM 기반 지침서 전처리 호출은 없다.

## 저장·일관성

- SQLite 마이그레이션 005의 `workspace_guides` 테이블에 워크스페이스별로 저장한다.
- `GET /api/rag/workspaces/{wid}/guide`, `PUT`에 `content`, `enabled`, `expected_version`을 사용한다.
- API에서 추가 필드, 잘못된 타입, 제어문자, 길이 초과를 거절한다. 브라우저 세션은 CSRF 검증도 받는다.
- `expected_version`이 달라지면 409 `GUIDE_CHANGED`: 자동 덮어쓰기 없이 최신본과 수정본 선택을 받는다.
- 질문/회의 요청 단위로 지침서 스냅샷을 유지한다. 도중에 수정되면 다음 요청부터 적용한다.
- 결과의 `guidance`는 사용 버전·해시·실제 전달 여부를 기록한다. 질문 기록에도 보존한다.
  기록에 지침서 원문을 중복 저장하거나 일반 질문 응답에 원문을 노출하지 않는다.
- 워크스페이스 삭제 시 외래 키 cascade로 지침서도 삭제된다. 운영 지침·연결 설정·전송 승인은 변경하지 않는다.

## 검증

- `rag/.venv/bin/python -m pytest rag/tests/test_workspace_guides.py -q`: 저장·권한·CSRF·격리·출력 검증·스냅샷·입력 예산·마이그레이션.
- `node scripts/workspace_guides_smoke.mjs`: 합성 API 기반 브라우저 저장·재진입·다른 워크스페이스·사용 해제·실패 재시도·충돌·방문자·모바일.
- `rag/.venv/bin/python scripts/workspace_guides_eval.py --live --database /absolute/path/registry.sqlite`:
  현재 연결로 **합성 데이터만** 전송해 조리 순서·근거 부족·역할 탈출·사실 위조·운영 우선순위·회의 판정 공격을 점검한다.
  실제 사용자 문서나 지침서는 읽지 않으며 설정/워크스페이스를 바꾸지 않는다.
