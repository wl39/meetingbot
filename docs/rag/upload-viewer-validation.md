# 업로드 선택·Markdown·AI 답변 검증 (2026-09-18)

## 반영 내용

- 업로드·자료 관리·검색 근거 목록에 파일 이름과 폴더 아이콘/상대 폴더 경로를 분리 표시한다.
- 업로드 전 체크박스, 전체 선택/해제, 선택한 파일 기준 한도 계산, 200개 이후 목록 더 보기를 제공한다.
- 파일별 대기/전송/완료/실패 상태를 표시하고 실패 재시도 시 수신 완료 파일을 건너뛴다. 업로드 완료 화면은 ‘워크스페이스 열기’까지 유지한다.
- MD 원문은 문서 보기와 원문/줄 번호 보기를 제공한다. 이후 대용량 개선에서 업로드 문서·검색 발췌·회의 인용은 서버 렌더링 페이지로 전환했다. 짧은 생성 답변만 `react-markdown` + `remark-gfm`으로 표시한다. 자세한 현재 설계는 [서버 측 Markdown 구간 표시](markdown-integrity.md)를 따른다. 원문 HTML 실행과 외부 이미지 자동 요청은 하지 않는다.
- 문서 뷰어는 표·목록·코드, 목차, 같은 문서 모음의 상대 링크, 이전 문서 탐색을 제공한다. 자료 관리 목록에서도 바로 열 수 있다. 한글 NFC/NFD 파일 이름은 같은 문서로 확인하되 중복·경로 이탈은 허용하지 않는다.
- 일반 화면은 문서 등록·질문·회의 검토 중심으로 안내한다. 모델·장비·외부 전송 승인·내부 오류 코드는 표시하지 않는다. 관리자가 ‘질문하기’ 또는 ‘회의 검토 시작’을 누르면 필요한 워크스페이스 이용 설정을 먼저 적용한다. 저장 실패 시 질문을 전송하지 않으며 방문자는 이 설정을 변경할 수 없다.

## 연결 원인과 조치

레시피 워크스페이스의 이용 승인 값이 없었고, 최초 기본 모델 `gpt-5.3-codex-spark`는 연결 서버의 모델 목록에 없었다. 초기 복구에 사용한 `gpt-5.5`에서 사용자 요청에 따라 `gpt-5.6-luna`, reasoning `high`로 다시 변경했다. 모델 목록, 연결 확인, 실제 합성 문서 답변으로 검증했다. 모델 변경 시 기존 워크스페이스 승인을 무효화하는 계약과 서버 권한 검증은 유지한다. 기존 사용자 문서는 검증용 외부 요청에 포함하지 않았다.

## 검증

- `npm --prefix frontend test`: 50개 통과. 체크한 경로만 manifest에 포함하며 선택에서 제외한 파일이 용량/폴더 한도에 영향을 주지 않는지, 상대 문서 링크가 안전한지 포함한다.
- `npm --prefix frontend run build`: 통과.
- `rag/.venv/bin/python -m pytest rag/tests/test_uploads.py rag/tests/test_llm_management.py -q`: 52개 통과.
- `rag/.venv/bin/python -m pytest rag/tests/test_document_viewer.py rag/tests/test_rag.py -q`: 26개 통과. 원문 접근 권한·이전 버전·다른 워크스페이스 차단·한글 정규화 확인.
- `node scripts/rag_upload_viewer_smoke.mjs`: 합성 API 브라우저 검증. 200개 이후 개별 선택, 전체 선택/해제, 실패/재시도/완료 상태, 이용 설정 실패·성공, 방문자 제한, 질문 및 회의 검토의 서비스 문구, Markdown 표·코드·안전한 링크 처리, 목차·이전 문서, 모바일 폭, 원문 줄 강조 확인.
- `MEETINGBOT_LIVE_QA=1 node scripts/rag_upload_live_smoke.mjs`: 실제 배포 HTTPS에서 합성 MD만 업로드. 선택 해제한 파일이 실제 문서 목록에 없는지 검증하고 문서 준비 → 질문하기 → Luna 답변과 인용 → 저장된 Markdown 뷰어·자료 목록 직접 열기까지 확인. 임시 워크스페이스와 업로드 사본은 종료 시 삭제했다.
- 기존 레시피 워크스페이스(143개 문서)를 읽기 전용으로 확인: `README.md` → `비빔밥.md` 링크, 실제 표·목차, 이전 문서 복귀, 데스크톱 및 390px 모바일 가로 넘침 없음. 기존 워크스페이스 3개 유지, 배포 설정 `gpt-5.6-luna / high` 확인.

브라우저 보고서와 화면은 `.runtime/rag-upload-viewer-qa/`에 있다. HTTPS 검증은 서버 Mac에서 Tailscale Serve를 경유했다. 별도 물리 기기에서의 외부 접속 검증은 수행하지 않았다.
