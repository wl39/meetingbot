# 공개 데모와 역할별 접속

## 실행

먼저 [설치 안내](installation.md)에 따라 프로그램과 필요한 모델을 준비한다. 아래 `YOUR_SOURCE_DIR`는 저장소를 내려받은 실제 폴더로 바꾼다.

기존 회의봇과 별도 프로세스·자료·접속 키로 실행한다. 로컬 포트는 STT/웹 8875, RAG 8876이다. 기존 8765/8766 서비스는 계속 사용할 수 있다.

```sh
cd /YOUR_SOURCE_DIR/meetingbot
./scripts/start.sh --demo
# 실제 인터넷 공개: 방문자는 Tailscale 설치나 접속 키가 필요 없다.
./scripts/start.sh --demo --public
```

macOS에서는 `scripts/start-demo.command` 또는 `scripts/start-public-demo.command`를 더블클릭해도 된다. Windows/Linux에서는 설치 후 `python scripts/demo.py` 또는 `python scripts/demo.py --public`을 사용한다. 이 실행 창을 열어 두어야 한다. Ctrl+C로 데모 프로세스와 해당 공개 연결을 종료한다. Mac이 종료되거나 잠자기에 들어가면 접속할 수 없다.

`--public`은 Tailscale Funnel의 HTTPS **10000 포트만** 사용한다. 기존 개인용 Serve 443/8443 설정은 바꾸지 않는다. 10000 포트가 이미 사용 중이면 덮어쓰지 않고 종료한다. 첫 Funnel 실행 시 Tailscale에서 계정 관리자에게 활성화를 요청할 수 있다. 실행기에 출력되는 `https://기기이름.네트워크.ts.net:10000` 주소를 공유한다.

Funnel 공식 문서는 조정할 수 없는 대역폭 제한이 있다고 밝히지만 Mbps·GB/일 수치는 공개하지 않는다. 하루 방문자 100명 지원을 보장하는 수치는 없다. 100명이 각각 10MB 음성을 업로드하면 업로드만 약 1GB이며, 하루 총 방문보다 동시 전사·음성 처리 시간이 실제 수용량을 좌우한다. 실제 외부 경로 부하 시험은 별도다. [Funnel 문서](https://tailscale.com/docs/features/tailscale-funnel)

## 아이폰에서 체험

실행기에 표시된 공개 HTTPS 링크를 Safari에서 연다. Tailscale 설치나 접속 키 없이 **게스트**로 바로 들어간다. 상단에 **공개 데모**가 표시되며, 이 안내를 누르면 이용 횟수와 기록 보관 안내를 펼칠 수 있다.

- **파일 전사 → 음성 파일 선택**에서 기기에 저장한 M4A·MP3·WAV·FLAC 녹음을 고른다.
- **실시간 전사 → 녹음 시작**을 누르고 마이크 접근을 허용한다. 녹음 중에는 화면을 열어 둔다. 데모에서는 3분 이내에 자동으로 녹음을 마친다.
- **자료 검색**에서 가상의 데모 자료를 검색한다.
- 관리자 키가 있다면 상단 열쇠 버튼으로 로그인한다. 게스트 체험에는 누를 필요가 없다.

휴대폰에서는 메뉴와 주요 동작 버튼의 터치 영역을 최소 44px로 제공하고, 입력란은 16px로 표시한다. 화면 가장자리의 안전 영역도 반영한다.

## 저장 위치와 모델

- macOS: `~/Library/Application Support/MeetingbotDemo`
- Windows: `%LOCALAPPDATA%/MeetingbotDemo`
- Linux: `$XDG_DATA_HOME/meetingbot-demo` 또는 `~/.local/share/meetingbot-demo`

데모 표식이 없는 기존 자료 폴더와 개인 설치의 자료 폴더는 데모 저장소로 사용할 수 없다. 개인 `.env`/`.env.rag`의 AI 연결·문서 루트·접속키는 데모 프로세스에 적용하지 않는다. 이미 설치한 음성 모델의 스냅샷과 임베딩 캐시는 추론에 재사용한다. 데모에서는 음성 엔진 추가 설치 API를 사용할 수 없으며 기존 설치에서 준비한다. 모델이 준비되어 있지 않으면 준비 필요 상태를 표시한다.

첫 실행에 가상의 회의 운영 가이드와 RAG 워크스페이스를 생성하고 색인한다. **“운영 서버 로그 보관 기간”**으로 검색을 체험할 수 있다. 실제 AI 답변·회의 도우미는 데모의 슈퍼관리자가 별도로 AI 연결과 자료 전송을 허용해야 한다. 처음에는 외부 LLM 연결을 복사하거나 호출하지 않는다. `--fake`는 음성 인식 검증용이며 화면에 모의 결과임을 별도로 표시한다. 공개 데모의 기본값은 실제 음성 인식이다.

## 권한

| 기능 | 방문자 | 관리자 | 슈퍼관리자 |
|---|---|---|---|
| 자기 음성 전사·수정·내보내기·삭제 | 가능 | 가능 | 가능 |
| 다른 사용자의 녹음·파일 전사 조회·관리 | 불가 | 불가 | 불가 |
| 공용 지식 자료 검색·질문 | 가능 | 가능 | 가능 |
| 내 기기 자료 업로드·자기 워크스페이스 관리 | 가능 | 가능 | 가능 |
| 공용 자료 관리·공유 서버 폴더 연결 | 불가 | 가능 | 가능 |
| 모델·AI 연결·전역 검색 설정 | 불가 | 불가 | 가능 |
| 접속 키 발급·폐기 | 불가 | 불가 | 가능 |

기존 개인 설치의 `local-token`은 슈퍼관리자 키로 유지된다. 설정 및 관리 → **접속 및 권한**에서 역할별 키를 발급한다. 발급한 키는 한 번만 표시하고 서버에는 해시만 저장한다. 키 폐기는 해당 키의 이후 요청과 로그인 세션을 무효화한다. 같은 방문자 키를 공유하면 같은 사용자로 취급하므로 각각 다른 키를 발급한다. 기존 RAG 쿠키는 인증 저장소가 바뀌면서 다시 로그인이 필요할 수 있다.

데모 최초 실행에는 다음 파일을 생성한다. 키 내용은 실행 로그에 출력하지 않는다.

- 슈퍼관리자: `MeetingbotDemo/stt/local-token`
- 관리자: `MeetingbotDemo/admin-key`
- 방문자: `MeetingbotDemo/visitor-key`

브라우저 상단 **접속 키로 로그인**에서 키를 입력한다. 키 없이 접속하면 방문자 쿠키가 자동 발급된다. 쿠키는 HttpOnly·SameSite=Strict이며 공개 HTTPS 모드에서는 Secure를 사용한다. 쿠키 인증 변경 요청은 CSRF와 Origin을 검증한다. 녹음·업로드한 음성 파일·대본·회의 분석 결과는 계정별로 분리하며 관리자와 슈퍼관리자도 자신의 기록만 조회·수정·삭제할 수 있다. 소유자가 없는 이전 기록은 다른 계정에 자동 배정하지 않는다. 방문자에게 공용 RAG 질문 이력은 공개하지 않는다. 세션·청크 업로드·다운로드·WebSocket·회의 분석에서도 소유권을 확인한다.

## 데모 한도

- 음성 파일: **3분 / 20MiB**, 실시간 마이크: **3분**.
- 전사: **동시 1건**, 방문자당 UTC 하루 **3건**, 데모 전체 **100건**. 한도가 아닌 엔진 상태·처리 시간에 따라 실제 성공 건수는 달라진다.
- AI 요청: 방문자당 하루 20건, 전체 300건. 회의 분석 한 건은 내부적으로 LLM을 두 번 호출할 수 있어 API 호출 300회 보장은 아니다.
- 자료 검색: 방문자당 하루 100건, 전체 3,000건.
- 새 익명 세션: 전체 하루 2,000건. 새 쿠키를 발급받아도 전체 처리 한도는 초기화되지 않는다.
- 원음 보관은 비활성화하고, 전사 기록은 24시간 경과 후 최대 10분 내 정리한다. 현재 처리 중인 기록은 종료 후 정리한다.
- 데모 RAG 질문·답변 로그도 하루 경과 후 정리한다. 관리자가 넣은 공용 지식 문서는 자동 삭제하지 않는다.

데모는 소수의 실제 기능 체험용이며 다중 사용자 SaaS의 처리량을 보장하지 않는다. 외부 LLM 사용 비용·계정 한도와 로컬 장비의 전력·연산은 별도다. 데모와 개인 서버를 동시에 사용할 경우 같은 장비의 메모리·연산을 공유한다.

## 확인한 범위

`backend/tests/test_access.py`, `rag/tests/test_access.py`는 역할 차단·소유권·익명 쿠키/CSRF·키 폐기·누적 한도를 검사한다. `scripts/demo_ui_smoke.mjs`는 독립 로컬 데모에서 브라우저 입장, 합성 오디오 업로드, 다른 방문자의 기록 접근 거부, 실제 로컬 임베딩 검색, 키 발급 UI, 모바일 레이아웃을 확인한다. 100명 동시 접속이나 Funnel의 실제 외부 대역폭을 측정하는 시험은 아니다.
