# 문서 안내

새 설치는 [설치 안내](installation.md)를 따릅니다. 원격 접속은 [Tailscale 안내](tailnet-access.md), 공개 체험 서버는 [공개 데모 안내](public-demo.md)를 참고하세요. 명령의 `YOUR_*`는 본인 설치의 실제 경로·호스트·IP로 바꿉니다.

이 폴더와 하위 폴더의 `*-results.json`, `*-smoke.json`, `*-deployment.json`, `*-validation.json` 및 테스트 결과 문서는 과거 개발 환경의 기록입니다. 새 설치에서 해당 시험이 실행되었거나 같은 성능이 나온다는 의미가 아닙니다. 개인 경로와 접속 주소는 자리표시자로 바꾸었으며, 기록에 있는 스크린샷·백업 경로는 공개 저장소에 포함된 파일을 뜻하지 않습니다. 현재 환경의 동작은 설치 후 테스트와 상태 확인으로 검증합니다.
